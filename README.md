**Meridian Bay** — an original open-world crime game built for the make.fun "Make GTA 6" bounty. A sun-soaked coastal city to explore on foot and by car: stealable cars, traffic and pedestrians, a 1–5 star wanted system with chasing police and roadblocks, pistol/melee combat, a 5-mission story arc (Kai Mercer caught between the Harbor Kings and the Vesper Syndicate), a live minimap, synthesized sound, and localStorage saves. Three.js 3D, static files only, no network at runtime.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or hand it in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Controls

WASD move/drive · Mouse orbit camera · Shift sprint · E enter/exit car · Space handbrake · Left click punch/shoot · R reload · M start next mission · Esc pause.
