Meridian Bay — an original open-world crime game: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police across a 5-star wanted system, and play through a 5-mission turf-war story between the Harbor Kings and the Vesper Syndicate. Traffic, pedestrians, combat, a live minimap, synthesized sound and localStorage saves — all in static files, no network needed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD to move/drive, mouse drag to orbit the camera, E to enter/exit a car, click to shoot/punch, Enter to start the next mission, Esc to pause.
