**Meridian Bay** — an original open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore a sun-soaked coastal city on foot and by car as Kai Mercer, a driver-for-hire caught between the Harbor Kings and the Vesper Syndicate: steal cars, outrun the police across a 5-star wanted system, and play through a 5-mission story arc with combat, traffic, pedestrians, a live minimap, saves, and synthesized sound — all in plain static files running on Three.js.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network at runtime.
